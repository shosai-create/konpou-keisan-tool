Threads投稿の下書きを作ります。投稿・ネット送信は絶対にしないこと。

1. `python3 pipeline.py brief` を実行し、表示された「下書きの型」「今回のテーマ」「出力形式」を読む。
2. テーマごとに3案、型を厳守して書く。特に：
   - 書き出しは引きつける一文、最後は未回収の伏線を1つ（hook / foreshadow は text の先頭・末尾と完全一致させる）
   - 「何が大事か」まで。手順・判断基準・チェックリスト・番号付きリスト（＝どうやるか）は書かない
   - 実名・学校名・塾名・会社名、案件が特定できる具体性（製品の種類・症状・受注や返品の経緯）は入れず、教訓だけに一般化する。memo に具体的な話があっても本文には持ち込まない
   - 化粧品の効能をうたう表現は入れない
   - 500文字以内
3. 結果を `drafts/_incoming.json` に書き、`python3 pipeline.py save drafts/_incoming.json` を実行する。
4. ✗（型違反）が出たらその案を直して再度 save。⚠（要確認）は、本当に問題なら直し、問題ないと判断したものは理由をひとこと添えて残す。
5. 保存できたら `drafts/_incoming.json` を削除し、保存先ファイル名と各案の文字数・⚠の有無を短く報告する。
